# Educa Data API

API REST para consulta e análise de dados educacionais brasileiros, utilizando os microdados do Censo Escolar do INEP.

## Sobre o projeto

O Educa Data API é um projeto desenvolvido com o objetivo de organizar, processar e disponibilizar dados educacionais públicos por meio de uma API REST.

A proposta inicial é utilizar os microdados do Censo Escolar para estruturar informações sobre instituições de ensino, permitindo consultas e análises de maneira mais acessível.

## Objetivos

- Processar e organizar os microdados do Censo Escolar.
- Estruturar os dados em um banco de dados relacional.
- Disponibilizar informações educacionais por meio de endpoints REST.
- Permitir consultas e filtros sobre as instituições de ensino.
- Desenvolver uma solução documentada e de fácil utilização.

## Tecnologias

- **Python** — linguagem principal.
- **Pandas** — processamento e manipulação de dados.
- **Django** — desenvolvimento da aplicação web.
- **Django REST Framework** — construção da API REST, planejada para uma etapa posterior.
- **PostgreSQL** — banco de dados planejado para o projeto.

*As tecnologias e funcionalidades serão atualizadas conforme o desenvolvimento avançar.*

## Fonte dos dados

Os dados utilizados no projeto têm como fonte os microdados do Censo Escolar, disponibilizados pelo Instituto Nacional de Estudos e Pesquisas Educacionais Anísio Teixeira (INEP).
